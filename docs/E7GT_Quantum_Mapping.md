# E7G-T to E7Q mapping

| E7G-T construct | E7Q interpretation |
|---|---|
| Configuration Γ | Quantum/classical registers, context, execution state |
| D5 possibility family | Admissible states, branches, circuits, or implementations |
| D6 transformation | Gate, unitary, channel, or compiler rewrite |
| D1 path | Ordered computation or compilation history |
| D3 structured object | Composed register, circuit, or module |
| D4 process/history | State evolution across stages |
| D2 projection/view | Measurement basis, observable, reduced state, or report |
| D0 local result | Shot outcome, expectation, accepted result, or diagnostic |
| D7 role/context | Backend, basis, shots, tolerance, noise model, and inquiry |
| Invariant | Normalisation, unitarity, symmetry, interface, or property |
| Projection loss | Information discarded by measurement, trace, aggregation, or noise |
| Operational phase | Equivalence class under an explicit criterion |
| Proof-of-Path | Auditable specification-to-compilation-to-measurement record |
| Temporal subkernel Θ | Bounded temporal-evidence profile over supplied and derived artifacts |
| TD0 temporal locality | Calibration snapshot, reported completion event, or one measurement/result |
| TD1 temporal line | Ordered circuit, compilation, Proof-of-Path, or handoff sequence |
| TD2 temporal surface | Branch, replication family, campaign comparison, or longitudinal history family |
| Temporal projection | State/history/artifact family reduced to measurement, counts, pooled distribution, or report |
| Temporal reconstruction fibre | Multiple execution histories compatible with the same observed counts or summary |
| Temporal phase | Equivalence under a declared freshness, repeatability, drift, trend, completion, or ordering criterion |
| Temporal boundary crossing | Freshness expiry, repeatability failure, drift threshold breach, or first trend breach |

Structural order and temporal order are independent. For example, one D2
document may be a TD0 snapshot, participate in a TD1 version history, or belong
to a TD2 family of alternative histories.

This is an engineering correspondence, not an identity claim between E7G-T and
quantum mechanics. TD0–TD7 are modelling roles, not claims about literal
physical time dimensions or a new quantum theory of time.
