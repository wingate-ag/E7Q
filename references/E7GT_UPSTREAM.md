# E7G-T upstream relationship

E7Q is a downstream experimental application of the E7G-T Unified Geometry-Thinking Kernel. The upstream kernel contributes a disciplined vocabulary for configuration, possibility families, transformations, paths, structured objects, processes, projections, results, contexts, invariants, operational equivalence, and Proof-of-Path.

E7Q does not infer quantum physics from that vocabulary. Executable meaning comes from established quantum theory: Hilbert spaces, tensor products, unitary operators, channels where supported, the Born rule, classical control, and declared backend constraints.

The canonical upstream kernel should be cited by immutable version and source location when its public canonical URL is fixed. This repository must not silently fork or rewrite it.
